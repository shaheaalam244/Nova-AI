# Nova AI - Intelligent Virtual Assistant

Nova AI is a modern, high-performance conversational AI assistant built with React, Vite, and Google Gemini 2.5 Flash.

## ✨ Features
- ⚡ Fast response times powered by Google Gemini 2.5 Flash
- 🎨 Sleek glassmorphic dark-mode UI with modern typography
- 📱 Responsive sidebar and prompt card interface
- 🔒 Secure Express backend server

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment
Create a `.env` file with your Gemini API key:
```env
GEMINI_API_KEY=your_api_key_here
```

### 3. Run Development Server
```bash
# Start backend server
npm run server

# Start frontend (in a separate terminal)
npm run dev
```
